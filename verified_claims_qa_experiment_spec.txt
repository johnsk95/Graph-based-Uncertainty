================================================================================
VERIFIED CLAIMS AS CONTEXT - QA EXPERIMENT SPECIFICATION
Knowledge Graph Downstream Utility Evaluation
================================================================================

OVERVIEW
--------
This specification defines an experiment to evaluate whether verified/grounded
claims from the knowledge graph can serve as effective context for question
answering. The experiment demonstrates the downstream utility of the knowledge
expansion framework.

Research Question:
    "Can verified, grounded claims created by our knowledge base serve as
     trusted, grounded context to answer questions about a paper?"

Dataset: Same QASPER papers used in the knowledge expansion experiment
Models:
    - Question Generation: GPT-4.1
    - Question Answering: GPT-4o-mini (all conditions)

================================================================================
PART 1: QUESTION GENERATION (SEPARATE MODULE)
================================================================================

1.1 Overview
------------
Generate 20 new questions per paper using GPT-4.1. These questions must:
    - NOT overlap with existing QASPER questions
    - NOT be answerable from title+abstract alone (require deeper content)
    - Have ground truth answers generated by the same LLM

1.2 Input Requirements
----------------------
For each paper, you need:
    - paper_id: str
    - title: str
    - abstract: str
    - full_text: dict (section_name -> paragraphs)
    - existing_qas: List[dict] (from QASPER dataset)

1.3 Question Generation Prompt
------------------------------
SYSTEM_PROMPT = """
You are an expert research paper analyst. Your task is to generate questions
about a scientific paper that:
1. Require information BEYOND the title and abstract to answer
2. Are specific to this paper's methodology, results, or technical details
3. Do NOT overlap with the existing questions provided
4. Have clear, factual answers derivable from the paper content

Focus on questions about:
- Specific experimental settings, hyperparameters, or configurations
- Quantitative results and comparisons
- Technical implementation details
- Limitations or future work mentioned
- Specific datasets, baselines, or evaluation metrics used
"""

USER_PROMPT_TEMPLATE = """
# Paper Title
{title}

# Abstract
{abstract}

# Full Paper Content
{full_text_formatted}

# Existing Questions (DO NOT generate similar questions)
{existing_questions_list}

# Task
Generate exactly 20 NEW questions about this paper that:
1. Cannot be answered by reading only the title and abstract
2. Are distinct from the existing questions listed above
3. Have specific, factual answers found in the paper

For each question, also provide the correct answer based on the paper content.

# Output Format
Return a JSON array with exactly 20 objects:
[
    {
        "question": "Your question here?",
        "answer": "The correct answer based on the paper",
        "evidence_section": "Name of section containing the answer"
    },
    ...
]
"""

1.4 Implementation Details
--------------------------
class QuestionGenerator:
    """
    Generate new questions for papers using GPT-4.1.
    """
    
    def __init__(self, openai_client, model="gpt-4.1"):
        self.client = openai_client
        self.model = model
    
    def format_full_text(self, full_text: dict) -> str:
        """
        Convert QASPER full_text structure to readable string.
        
        Args:
            full_text: {"section_name": [...], "paragraphs": [[...], ...]}
        
        Returns:
            Formatted string with section headers and paragraphs
        """
        formatted = []
        section_names = full_text.get("section_name", [])
        paragraphs = full_text.get("paragraphs", [])
        
        for i, section_name in enumerate(section_names):
            formatted.append(f"\n## {section_name}\n")
            if i < len(paragraphs):
                for para in paragraphs[i]:
                    formatted.append(para)
                    formatted.append("")  # Empty line between paragraphs
        
        return "\n".join(formatted)
    
    def format_existing_questions(self, qas: list) -> str:
        """
        Format existing QASPER questions as a numbered list.
        """
        questions = [qa["question"] for qa in qas]
        return "\n".join([f"{i+1}. {q}" for i, q in enumerate(questions)])
    
    def generate_questions(self, paper: dict) -> list:
        """
        Generate 20 new questions for a paper.
        
        Args:
            paper: QASPER paper dict with id, title, abstract, full_text, qas
        
        Returns:
            List of {"question": str, "answer": str, "evidence_section": str}
        """
        full_text_formatted = self.format_full_text(paper["full_text"])
        existing_questions = self.format_existing_questions(paper["qas"])
        
        user_prompt = USER_PROMPT_TEMPLATE.format(
            title=paper["title"],
            abstract=paper["abstract"],
            full_text_formatted=full_text_formatted,
            existing_questions_list=existing_questions
        )
        
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[
                {"role": "system", "content": SYSTEM_PROMPT},
                {"role": "user", "content": user_prompt}
            ],
            temperature=0.7,
            response_format={"type": "json_object"}
        )
        
        # Parse response
        content = response.choices[0].message.content
        result = json.loads(content)
        
        # Handle both direct array and wrapped object responses
        if isinstance(result, list):
            questions = result
        elif "questions" in result:
            questions = result["questions"]
        else:
            raise ValueError(f"Unexpected response format: {result.keys()}")
        
        # Validate we got 20 questions
        if len(questions) != 20:
            print(f"Warning: Got {len(questions)} questions instead of 20")
        
        return questions
    
    def validate_questions(
        self,
        questions: list,
        existing_qas: list,
        similarity_threshold: float = 0.85
    ) -> list:
        """
        Filter out questions that are too similar to existing ones.
        Uses simple token overlap for efficiency.
        
        Args:
            questions: Generated questions
            existing_qas: Existing QASPER questions
            similarity_threshold: Jaccard similarity threshold for filtering
        
        Returns:
            Filtered list of questions
        """
        existing_questions = [qa["question"].lower() for qa in existing_qas]
        
        def jaccard_similarity(q1: str, q2: str) -> float:
            tokens1 = set(q1.lower().split())
            tokens2 = set(q2.lower().split())
            intersection = tokens1 & tokens2
            union = tokens1 | tokens2
            return len(intersection) / len(union) if union else 0
        
        filtered = []
        for q in questions:
            q_text = q["question"]
            max_sim = max(
                jaccard_similarity(q_text, eq) for eq in existing_questions
            ) if existing_questions else 0
            
            if max_sim < similarity_threshold:
                filtered.append(q)
            else:
                print(f"Filtered similar question: {q_text[:50]}...")
        
        return filtered

1.6 Question Generation Script
------------------------------
def generate_questions_for_papers(
    papers: list,
    output_path: str,
    openai_api_key: str
) -> dict:
    """
    Generate questions for all papers and save to JSON.
    
    Args:
        papers: List of QASPER paper dicts
        output_path: Path to save JSON output
        openai_api_key: OpenAI API key
    
    Returns:
        Generated questions dict
    """
    from openai import OpenAI
    import json
    from datetime import datetime
    
    client = OpenAI(api_key=openai_api_key)
    generator = QuestionGenerator(client, model="gpt-4.1")
    
    output = {
        "generated_at": datetime.utcnow().isoformat() + "Z",
        "model": "gpt-4.1",
        "papers": []
    }
    
    for paper in papers:
        print(f"Generating questions for paper: {paper['id']}")
        
        try:
            questions = generator.generate_questions(paper)
            questions = generator.validate_questions(questions, paper["qas"])
            
            # Add question IDs
            for i, q in enumerate(questions):
                q["question_id"] = f"gen_{paper['id']}_{i+1:03d}"
            
            paper_entry = {
                "paper_id": paper["id"],
                "title": paper["title"],
                "num_existing_questions": len(paper["qas"]),
                "generated_questions": questions
            }
            output["papers"].append(paper_entry)
            
        except Exception as e:
            print(f"Error generating questions for {paper['id']}: {e}")
            continue
    
    # Save to file
    with open(output_path, 'w') as f:
        json.dump(output, f, indent=2)
    
    print(f"Saved {len(output['papers'])} papers to {output_path}")
    return output

2.1 Overview
------------
Use verified/grounded claims from the knowledge graph as context for answering
the generated questions. Compare against baselines using different contexts.

Conditions:
    1. VERIFIED_CLAIMS: Grounded claims from knowledge graph
    2. BASELINE_ABSTRACT: Title + Abstract only
    3. BASELINE_FULL: Full paper text

All conditions use GPT-4o-mini as the answering LLM.

2.2 Loading Verified Claims
---------------------------
def load_verified_claims(graph_path: str, paper_id: str) -> list:
    """
    Load grounded/verified claims for a paper from the knowledge graph.
    
    Args:
        graph_path: Path to saved NetworkX graph (pickle or JSON)
        paper_id: Paper ID to filter claims
    
    Returns:
        List of claim texts that are grounded/verified
    """
    import networkx as nx
    import pickle
    
    # Load graph (adjust based on your serialization format)
    with open(graph_path, 'rb') as f:
        graph = pickle.load(f)
    
    verified_claims = []
    
    for node_id, node_data in graph.nodes(data=True):
        # Check if this is a claim node for the target paper
        if node_data.get('type') != 'claim':
            continue
        if node_data.get('paper_id') != paper_id:
            continue
        
        # Check if claim is grounded/verified
        # Adjust these conditions based on your graph schema
        status = node_data.get('status', '')
        if status in ['grounded', 'verified', 'accepted']:
            claim_text = node_data.get('text', node_data.get('content', ''))
            if claim_text:
                verified_claims.append({
                    "claim_id": node_id,
                    "text": claim_text,
                    "status": status
                })
    
    return verified_claims

2.3 Context Formatting
----------------------
def format_claims_as_context(claims: list) -> str:
    """
    Format verified claims as context for the QA model.
    
    Args:
        claims: List of {"claim_id": str, "text": str, "status": str}
    
    Returns:
        Formatted context string
    """
    if not claims:
        return "No verified information available."
    
    context_lines = ["The following are verified facts about this paper:"]
    context_lines.append("")
    
    for i, claim in enumerate(claims, 1):
        context_lines.append(f"{i}. {claim['text']}")
    
    return "\n".join(context_lines)


def format_abstract_context(paper: dict) -> str:
    """
    Format title + abstract as context.
    """
    return f"# {paper['title']}\n\n## Abstract\n{paper['abstract']}"


def format_full_paper_context(paper: dict) -> str:
    """
    Format full paper as context.
    """
    lines = [f"# {paper['title']}", "", "## Abstract", paper['abstract'], ""]
    
    section_names = paper["full_text"].get("section_name", [])
    paragraphs = paper["full_text"].get("paragraphs", [])
    
    for i, section_name in enumerate(section_names):
        lines.append(f"## {section_name}")
        if i < len(paragraphs):
            for para in paragraphs[i]:
                lines.append(para)
                lines.append("")
    
    return "\n".join(lines)

2.4 Question Answering Prompts
------------------------------
QA_SYSTEM_PROMPT = """
You are a helpful assistant that answers questions about scientific papers.
Answer questions using ONLY the information provided in the context.
If the context does not contain enough information to answer the question,
say "Cannot be determined from the given information."

Be concise and specific in your answers.
"""

QA_USER_PROMPT_TEMPLATE = """
# Context
{context}

# Question
{question}

# Instructions
Answer the question using only the information provided in the context above.
Provide a concise, specific answer.
"""

2.5 QA Implementation
---------------------
class ClaimsBasedQA:
    """
    Answer questions using different context conditions.
    """
    
    def __init__(self, openai_client, model="gpt-4o-mini"):
        self.client = openai_client
        self.model = model
    
    def answer_question(self, question: str, context: str) -> dict:
        """
        Answer a single question given context.
        
        Args:
            question: Question text
            context: Context string (claims, abstract, or full paper)
        
        Returns:
            {"answer": str, "tokens_used": int}
        """
        user_prompt = QA_USER_PROMPT_TEMPLATE.format(
            context=context,
            question=question
        )
        
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[
                {"role": "system", "content": QA_SYSTEM_PROMPT},
                {"role": "user", "content": user_prompt}
            ],
            temperature=0.0,  # Deterministic for reproducibility
            max_tokens=500
        )
        
        return {
            "answer": response.choices[0].message.content,
            "tokens_used": response.usage.total_tokens
        }
    
    def run_qa_experiment(
        self,
        paper: dict,
        questions: list,
        verified_claims: list,
        graph_path: str
    ) -> dict:
        """
        Run QA experiment for a single paper across all conditions.
        
        Args:
            paper: QASPER paper dict
            questions: List of generated questions with ground truth
            verified_claims: List of verified claims for this paper
            graph_path: Path to knowledge graph (for loading claims)
        
        Returns:
            Results dict with answers for each condition
        """
        # Prepare contexts
        claims_context = format_claims_as_context(verified_claims)
        abstract_context = format_abstract_context(paper)
        full_context = format_full_paper_context(paper)
        
        results = {
            "paper_id": paper["id"],
            "num_verified_claims": len(verified_claims),
            "num_questions": len(questions),
            "conditions": {
                "verified_claims": [],
                "baseline_abstract": [],
                "baseline_full": []
            }
        }
        
        for q in questions:
            question_text = q["question"]
            ground_truth = q["answer"]
            
            # Condition 1: Verified Claims
            claims_result = self.answer_question(question_text, claims_context)
            results["conditions"]["verified_claims"].append({
                "question_id": q["question_id"],
                "question": question_text,
                "ground_truth": ground_truth,
                "predicted_answer": claims_result["answer"],
                "tokens_used": claims_result["tokens_used"]
            })
            
            # Condition 2: Abstract Only
            abstract_result = self.answer_question(question_text, abstract_context)
            results["conditions"]["baseline_abstract"].append({
                "question_id": q["question_id"],
                "question": question_text,
                "ground_truth": ground_truth,
                "predicted_answer": abstract_result["answer"],
                "tokens_used": abstract_result["tokens_used"]
            })
            
            # Condition 3: Full Paper
            full_result = self.answer_question(question_text, full_context)
            results["conditions"]["baseline_full"].append({
                "question_id": q["question_id"],
                "question": question_text,
                "ground_truth": ground_truth,
                "predicted_answer": full_result["answer"],
                "tokens_used": full_result["tokens_used"]
            })
        
        return results

PART 3: EVALUATION WITH LLM JUDGE
================================================================================

3.1 Overview
------------
Use GPT-4.1 as an LLM judge to evaluate answer correctness. The judge receives
the question, ground truth answer, and predicted answer, then returns True/False.

Evaluation Model: GPT-4.1
Output: Boolean judgment (True = correct, False = incorrect)

3.2 LLM Judge Implementation
----------------------------
JUDGE_SYSTEM_PROMPT = """
You are an expert evaluator for question-answering systems. Your task is to
determine whether a predicted answer is correct by comparing it to the ground
truth answer.

Rules for evaluation:
1. The predicted answer does NOT need to match the ground truth exactly
2. The predicted answer is CORRECT if it conveys the same essential information
3. Minor differences in wording, phrasing, or additional context are acceptable
4. The predicted answer is INCORRECT if it:
   - States different facts than the ground truth
   - Misses key information from the ground truth
   - Says the question cannot be answered when a valid answer exists
   - Provides wrong numbers, names, or specific details

Respond with ONLY "True" or "False" - no explanation needed.
"""

JUDGE_USER_PROMPT_TEMPLATE = """
Question: {question}

Ground Truth Answer: {ground_truth}

Predicted Answer: {predicted_answer}

Is the predicted answer correct? Respond with only "True" or "False".
"""


class LLMJudge:
    """
    Use GPT-4.1 to judge answer correctness.
    """
    
    def __init__(self, openai_client, model="gpt-4.1"):
        self.client = openai_client
        self.model = model
    
    def judge_answer(
        self,
        question: str,
        ground_truth: str,
        predicted_answer: str
    ) -> dict:
        """
        Judge whether a predicted answer is correct.
        
        Args:
            question: The question that was asked
            ground_truth: The correct answer
            predicted_answer: The model's predicted answer
        
        Returns:
            {"is_correct": bool, "raw_response": str}
        """
        user_prompt = JUDGE_USER_PROMPT_TEMPLATE.format(
            question=question,
            ground_truth=ground_truth,
            predicted_answer=predicted_answer
        )
        
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[
                {"role": "system", "content": JUDGE_SYSTEM_PROMPT},
                {"role": "user", "content": user_prompt}
            ],
            temperature=0.0,  # Deterministic judgments
            max_tokens=10
        )
        
        raw_response = response.choices[0].message.content.strip()
        
        # Parse boolean response
        is_correct = raw_response.lower() == "true"
        
        return {
            "is_correct": is_correct,
            "raw_response": raw_response
        }
    
    def judge_batch(
        self,
        results: list
    ) -> list:
        """
        Judge a batch of QA results.
        
        Args:
            results: List of {"question": str, "ground_truth": str, 
                             "predicted_answer": str, ...}
        
        Returns:
            List of results with added "is_correct" and "judge_response" fields
        """
        judged_results = []
        
        for r in results:
            judgment = self.judge_answer(
                question=r["question"],
                ground_truth=r["ground_truth"],
                predicted_answer=r["predicted_answer"]
            )
            
            judged_result = r.copy()
            judged_result["is_correct"] = judgment["is_correct"]
            judged_result["judge_response"] = judgment["raw_response"]
            judged_results.append(judged_result)
        
        return judged_results

3.3 Answerability Detection
---------------------------
UNANSWERABLE_PATTERNS = [
    "cannot be determined",
    "not enough information",
    "cannot answer",
    "no information",
    "not mentioned",
    "not provided",
    "not specified",
    "unclear from",
    "not stated"
]

def is_unanswerable_response(answer: str) -> bool:
    """
    Check if the model indicated it couldn't answer.
    """
    answer_lower = answer.lower()
    return any(pattern in answer_lower for pattern in UNANSWERABLE_PATTERNS)

3.4 Metrics Computation
-----------------------
def evaluate_condition(results: list) -> dict:
    """
    Compute metrics for a single condition after LLM judging.
    
    Args:
        results: List of judged QA results with "is_correct" field
    
    Returns:
        Aggregated metrics dict
    """
    if not results:
        return {
            "num_questions": 0,
            "num_correct": 0,
            "accuracy": 0.0,
            "num_answerable": 0,
            "answerability_rate": 0.0,
            "total_tokens": 0
        }
    
    num_correct = sum(1 for r in results if r.get("is_correct", False))
    num_answerable = sum(
        1 for r in results 
        if not is_unanswerable_response(r["predicted_answer"])
    )
    total_tokens = sum(r.get("tokens_used", 0) for r in results)
    n = len(results)
    
    # Accuracy among answerable questions only
    answerable_results = [
        r for r in results 
        if not is_unanswerable_response(r["predicted_answer"])
    ]
    num_correct_answerable = sum(
        1 for r in answerable_results if r.get("is_correct", False)
    )
    
    return {
        "num_questions": n,
        "num_correct": num_correct,
        "accuracy": num_correct / n if n > 0 else 0.0,
        "num_answerable": num_answerable,
        "answerability_rate": num_answerable / n if n > 0 else 0.0,
        "accuracy_when_answerable": (
            num_correct_answerable / num_answerable 
            if num_answerable > 0 else 0.0
        ),
        "total_tokens": total_tokens,
        "avg_tokens_per_question": total_tokens / n if n > 0 else 0
    }

4.1 Full Pipeline
-----------------
def run_full_experiment(
    papers: list,
    generated_questions_path: str,
    graph_dir: str,
    output_path: str,
    openai_api_key: str
) -> dict:
    """
    Run the complete QA experiment.
    
    Args:
        papers: List of QASPER paper dicts
        generated_questions_path: Path to JSON with generated questions
        graph_dir: Directory containing knowledge graphs per paper
        output_path: Path to save results
        openai_api_key: OpenAI API key
    
    Returns:
        Complete results dict
    """
    from openai import OpenAI
    import json
    from datetime import datetime
    
    # Initialize
    client = OpenAI(api_key=openai_api_key)
    qa_system = ClaimsBasedQA(client, model="gpt-4o-mini")
    judge = LLMJudge(client, model="gpt-4.1")
    
    # Load generated questions
    with open(generated_questions_path, 'r') as f:
        questions_data = json.load(f)
    
    # Create paper_id -> questions mapping
    questions_by_paper = {
        p["paper_id"]: p["generated_questions"]
        for p in questions_data["papers"]
    }
    
    # Results storage
    all_results = {
        "experiment_timestamp": datetime.utcnow().isoformat() + "Z",
        "qa_model": "gpt-4o-mini",
        "question_generation_model": "gpt-4.1",
        "judge_model": "gpt-4.1",
        "papers": [],
        "aggregate_metrics": {}
    }
    
    # Process each paper
    for paper in papers:
        paper_id = paper["id"]
        
        if paper_id not in questions_by_paper:
            print(f"No generated questions for paper {paper_id}, skipping")
            continue
        
        questions = questions_by_paper[paper_id]
        
        # Load verified claims for this paper
        graph_path = f"{graph_dir}/{paper_id}_graph.pkl"
        try:
            verified_claims = load_verified_claims(graph_path, paper_id)
        except FileNotFoundError:
            print(f"No graph found for paper {paper_id}, skipping")
            continue
        
        print(f"Processing paper {paper_id}: {len(questions)} questions, "
              f"{len(verified_claims)} verified claims")
        
        # Run QA experiment
        paper_results = qa_system.run_qa_experiment(
            paper=paper,
            questions=questions,
            verified_claims=verified_claims,
            graph_path=graph_path
        )
        
        # Judge answers for each condition using LLM judge
        print(f"  Judging answers with GPT-4.1...")
        for condition_name in paper_results["conditions"]:
            condition_results = paper_results["conditions"][condition_name]
            
            # Judge each answer
            judged_results = judge.judge_batch(condition_results)
            paper_results["conditions"][condition_name] = judged_results
            
            # Compute metrics
            paper_results[f"{condition_name}_metrics"] = evaluate_condition(
                judged_results
            )
        
        all_results["papers"].append(paper_results)
    
    # Aggregate metrics across all papers
    all_results["aggregate_metrics"] = aggregate_all_metrics(all_results["papers"])
    
    # Save results
    with open(output_path, 'w') as f:
        json.dump(all_results, f, indent=2)
    
    print(f"Experiment complete. Results saved to {output_path}")
    return all_results


def aggregate_all_metrics(paper_results: list) -> dict:
    """
    Aggregate metrics across all papers.
    """
    conditions = ["verified_claims", "baseline_abstract", "baseline_full"]
    
    aggregated = {}
    
    for condition in conditions:
        metrics_key = f"{condition}_metrics"
        
        total_questions = 0
        total_correct = 0
        total_answerable = 0
        total_correct_answerable = 0
        total_tokens = 0
        
        for paper in paper_results:
            if metrics_key in paper:
                m = paper[metrics_key]
                total_questions += m["num_questions"]
                total_correct += m["num_correct"]
                total_answerable += m["num_answerable"]
                # Compute correct among answerable for this paper
                answerable_accuracy = m.get("accuracy_when_answerable", 0)
                total_correct_answerable += int(
                    answerable_accuracy * m["num_answerable"]
                )
                total_tokens += m["total_tokens"]
        
        aggregated[condition] = {
            "num_papers": len(paper_results),
            "total_questions": total_questions,
            "total_correct": total_correct,
            "accuracy": total_correct / total_questions if total_questions > 0 else 0,
            "total_answerable": total_answerable,
            "answerability_rate": (
                total_answerable / total_questions if total_questions > 0 else 0
            ),
            "accuracy_when_answerable": (
                total_correct_answerable / total_answerable 
                if total_answerable > 0 else 0
            ),
            "total_tokens": total_tokens
        }
    
    return aggregated

6.6 Expected Hypothesis
-----------------------
We expect to observe:

1. VERIFIED_CLAIMS vs BASELINE_ABSTRACT:
   - Higher answerability rate (claims contain more info than abstract)
   - Higher accuracy (claims are more specific and verified)
   
2. VERIFIED_CLAIMS vs BASELINE_FULL:
   - Similar or slightly lower accuracy (full paper has all info)
   - BUT: Much better token efficiency (claims are compressed)
   - Shows value of knowledge graph as efficient, trusted context

3. Key insight:
   - Verified claims provide a "best of both worlds": more information than
     abstract, more efficient than full paper, and epistemically validated.

6.7 Cost Estimation
-------------------
Per paper (20 questions, 3 conditions):
    - Question generation: ~1 GPT-4.1 call (long context)
    - QA: 60 GPT-4o-mini calls (20 questions × 3 conditions)
    - Judging: 60 GPT-4.1 calls (20 questions × 3 conditions)

For 50 papers:
    - Question generation: 50 GPT-4.1 calls
    - QA: 3,000 GPT-4o-mini calls
    - Judging: 3,000 GPT-4.1 calls


================================================================================
PART 7: ERROR HANDLING AND EDGE CASES
================================================================================

7.1 Question Generation Failures
--------------------------------
- If GPT-4.1 returns < 20 questions, log warning and proceed
- If JSON parsing fails, retry with explicit JSON formatting instruction
- If similarity filtering removes too many questions (< 10), lower threshold

7.2 Graph Loading Failures
--------------------------
- If graph file not found, skip paper and log
- If no verified claims found, use empty context (test "cannot determine" rate)

7.3 API Rate Limits
-------------------
- Implement exponential backoff for OpenAI API calls
- Consider batching where possible
- Log token usage for cost tracking

7.4 Long Context Handling
-------------------------
- GPT-4o-mini has 128k context limit
- If full paper exceeds limit, truncate from end (keep abstract/intro)
- Log when truncation occurs
